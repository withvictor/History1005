# 清末至1949年五地生活與大事小說史料手冊

1860年代至1949年：上海、廣州、北京與北平、東北、臺灣。

這份史料導航供歷史小說研究使用，以大事年表定位政權、戰爭與制度轉折，再把衣食住行、工作、家庭、語言與文化放回具體年份和人群。主體至1949年12月，必要時回溯更早的開港背景。原手冊資料查核日期為2026年10月3至4日；新增專題另註查核日期。

## 從這裡開始

1. 先讀[資料使用方式](docs/00-reading-guide.md)，確認日期、地點、身分與證據界線。
2. 用[雙線年表](docs/01-timeline.md)選定事件與月份，再進入相關地方章節。
3. 寫每一幕時對照[寫作查證清單](docs/08-writing-checklist.md)。正文中的來源編碼可直接跳到註解；[來源索引](sources/README.md)保留原件、研究、館藏入口與存取限制。

## 地域與主題

- 上海：街道與管轄、工業勞動、家計調查、戰時避難、1949年生活
- 廣州：學徒與茶樓、跨江移動、市政規章、家計與工價、佔領及港幣過渡
- 北京與北平：店員與車夫、街市與學校、居住和家庭器物、1949年接管
- 東北：奉天／瀋陽、哈爾濱、大連各自的管轄、鐵路、勞動、移民與貨幣時間線
- 臺灣：殖民生活、家庭與教育、戰時動員、戰後語言、物價與遷徙
- 跨地比較：衣食住行、工作與收入、貨幣、家庭制度，以及資料不可直接橫比的原因

## 使用界線

- 場景卡中的情節與感受是虛構寫作提案。史料所記、可能推論與創作必須分開。
- 每則數字保留年代、地點、幣種、單位與樣本範圍，不換算成今日購買力；調查平均數不是每一戶的實況。
- 法令、回憶、報刊、照片與學術研究各有證據限度。沒有核讀的全文，不因列入書目便算已驗證。
- 來源與書目現有263筆索引紀錄，其中包括同一著作的不同用途條目；索引筆數不代表獨立著作數。

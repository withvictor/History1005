這是「需要查什麼」的清單，不是尚未核實的生活結論。可把它當每一章交稿前的審核表。

- [ ] 先寫一張身分卡：具體年月、城鎮、街區、性別／年齡、籍貫與移住經驗、收入來源、識字能力、家庭負擔。別只寫「民初普通人」。

- [ ] 歷法與時間：日期原文用年號、民國紀年、公曆還是舊曆？書信與官方文書可能不同。年號換算後還要核對改元、閏月與節日日期；不能只換年份。臺灣資料常見日本年號，例如《臺灣民報》1923年創刊號題「大正十二年」。[[HX11](../sources/05-chronology.md#source-hx11)]

- [ ] 官署、職稱與管轄：在何處報案、納稅、登記或打官司？人物說的是日常稱呼還是正式職稱？同城不同管轄區要分開。臺灣 1920 年改為五州二廳，1926 年成為五州三廳，是會改變地址與公文稱呼的例子。[[HX08](../sources/05-chronology.md#source-hx08)]

- [ ] 地圖必須同年或近年：街名、橋、市界、碼頭、城門、河道有沒有改動？舊地圖圖例與比例尺是否讀懂？不要用今日步行距離推算當時路線。

- [ ] 交通要算整段成本：從家到站、候車、換乘、行李、渡河、停航、入城都算。列車已通車，不等於人物付得起或班次方便。臺灣 1891／1893 的北部鐵路與 1908 的西部縱貫鐵路不可混為一談。[[HX04](../sources/05-chronology.md#source-hx04)、[HX05](../sources/05-chronology.md#source-hx05)]

- [ ] 跨海與跨境：確認實際航線、船公司、艙等、開航日、港口檢查與當年旅券要求；不要把兩個港口有貿易當成每天都有直航。

- [ ] 錢要有幣種和地點：「一元」是哪種錢？銀兩、銀元、銅元、紙幣或臺灣流通貨幣如何折算？面值、帳面單位、實收與折扣可能不同。每個價錢至少配同年同地的工資或物價，禁止硬套今日匯率。

- [ ] 家庭預算比豪華菜單有用：一日幾餐？米、麵、雜糧與副食怎麼買？家裡是否有廚房、燃料與水？外食是便利、工作所迫還是娛樂？「有販售」不是「人人常吃」。

- [ ] 穿衣看整套，不只看旗袍或長衫：布料、內衣、鞋襪、補丁、雨具、換洗頻率、季節與工種；同一人物上工、出門、婚喪可能不同。用有日期與拍攝背景的照片，不把棚拍時裝當街頭常態。

- [ ] 房屋要畫平面：一間房住幾人？哪裡生火、放水、曬衣、上廁所、收垃圾？鄰居可以聽見／看見什麼？參看上海普通居住研究的問題意識，再核對個案。[[HB01](../bibliography/README.md#source-hb01)]

- [ ] 找工作靠誰：同鄉、親族、師徒、介紹人、店主、包工頭或正式招募？日薪、月薪、計件、包食宿不可混用；停工是否立刻斷糧？女工尤其要分行業與籍貫。[[HB02](../bibliography/README.md#source-hb02)、[HB06](../bibliography/README.md#source-hb06)]

- [ ] 說話與識字分開：能讀漢文不等於能用官話交談；懂某種語言也不等於敢向官署使用。人物接觸報紙，可以是自己讀、聽人讀或看圖，別讓識字成為不經查證的默認。[[HB12](../bibliography/README.md#source-hb12)]

- [ ] 社會身分會改變同一件事的難度：婦女、兒童、流動人口、工匠、店員、佃農、失業者及地方菁英的資源不同。精英日記不能直接代表「一般百姓」。

- [ ] 警察不是跨城通用角色：查制服、稱呼、管轄、巡邏、派出據點、報案程序，以及與街坊、保甲或其他基層組織的關係。北京街頭警察的研究只能先作北京線索。[[HB03](../bibliography/README.md#source-hb03)]

- [ ] 生病時先查可及性：附近有什麼醫療者？如何診斷、付費、取藥、照顧？家庭觀念、宗教與醫學可能交錯。不要把醫院已成立等同普遍可用，也不要提前放入尚未在當地普及的療法。[[HB11](../bibliography/README.md#source-hb11)]

- [ ] 信仰落到具體機構與行動：哪座廟、哪個教會、哪種地方祭典？誰組織、誰出錢、誰參加？不要把所有原住民族、漢人宗教或基督徒寫成同一套風俗。[[HB09](../bibliography/README.md#source-hb09)、[HB10](../bibliography/README.md#source-hb10)]

- [ ] 休閒看門檻與時間：戲票價、場次、觀眾構成、性別限制及工作日程；家庭收音機、唱機、電影等都須查實際普及度，不能把一則商品廣告當全民生活。[[HB05](../bibliography/README.md#source-hb05)]

- [ ] 知曉大事有時間差：角色什麼時候、透過誰聽到消息？讀到的報紙可能有立場、刪改與過期；不要讓1923年的角色預知1927或1931的結果。[[HX11](../sources/05-chronology.md#source-hx11)]

- [ ] 政治變動不等於生活一夜重置：法律公布、機關改名、地方執行、民間習慣可能有落差；把「規定如此」與「實際如此」分欄記錄。

- [ ] 記錄證據強度：原始帳簿／調查、同時代報刊、照片、日記、回憶錄、後來研究分開；對話可以創作，具體價格、路線、機構和制度卻應留下可核查依據。

<a id="section-1235"></a>

## 場景查核紀錄

每一幕建立一行紀錄：城市／行政區—公曆日期與農曆日期—人物職業與家計—事實句—來源 CN 編碼—原頁／章名—資料產生年—可否代表此人—尚待核查。

優先核的十項：

- [ ] 真實街名、街道是否已開闢、過界地點。

- [ ] 交通工具、路線、營運年與末班，不單核工具已發明。

- [ ] 職業的雇用方式與包食宿條件。

- [ ] 工資的幣種、支付周期、實際工作日。

- [ ] 食物季節、階級與宗教／地域差異。

- [ ] 屋租是按間、按戶、床位還是整宅。

- [ ] 衣著年代、階級、勞動場合與季節。

- [ ] 警察／巡捕／縣衙／會審機構的管轄。

- [ ] 家庭成員的實際貢獻，不只記男性現金工資。

- [ ] 報紙消息的報導日與事件日；廣告與制度條文只能證「刊載／規範」，不等於實際普及。

本冊沒有用未校讀的 OCR 表格造出物價清單，沒有把有權限的資料庫宣稱成免費，也沒有把晚清、1910 年代、1920 年代與 1930 年代物件混成同一時代。

<a id="section-1249"></a>

## 從證據到場景

每一個場景最好湊齊三種證據，而不是增加沒有用途的連結：

- 空間證據：近年地圖、照片、地籍或街道描述，解答「人站在哪裡」。

- 生活證據：同時代物價、工資、家庭調查、廣告、日記或帳簿，解答「他實際有什麼、買得起什麼」。

- 制度與解釋：當時法令／官署資料配合後來學術研究，解答「為何要這樣做、誰有選擇」。

同一個問題的不同材料互相牴觸時，先記錄作者身分、目的、地區、時間及採樣人群；不要急著選最戲劇化的一條。殖民政府、租界機關、革命團體、商人與傳教士都可能留下珍貴且偏向自身立場的記錄。可靠機構保存的是材料的來源與脈絡，不會自動使原作者的每句話變成事實。

<a id="section-1255"></a>

## 戰爭與政權轉換中的生活查證

- [ ] 人物先決定城市、年月、族群、身分與收入來源，再選服裝、食物、稱呼及交通。

- [ ] 法令證明規則存在，不能單獨證明每個地方如實施行；成果新聞也不能直接等同人人生活改善。

- [ ] 日記與口述能提供細節，但應保留「此人、此地、此時」的限制。

- [ ] 物價必須同時附日期、地點、幣種、商品等級及原單位；缺少工資、家庭人數、供給渠道時，不編造月生活費。

- [ ] 戒嚴下的臺灣、已受中共控制的哈爾濱、剛經1948年戰役的瀋陽與蘇聯影響下的旅大，不能合成同一種1949年中國生活。

<a id="section-1261"></a>

## 特定人物與物件的補充查核

- [ ] 一日三餐的精確價格、月租、車費、薪水：先指定年／月、街區、職業和幣種。本篇沒有可靠全三城逐年價格表，不以網路通俗「一塊大洋能買多少」補空白。

- [ ] 廣州平民住房、水上家庭、北京具體胡同的室內陳設：目前來源不足以逐項下定論。若人物確定於此，優先找地方調查、同時代照片和家計帳。

- [ ] 外來人口確切數字：不同時點、轄區、難民定義差很大，不以今日市界和人口回推。

- [ ] 演出、電影、收音機節目及廣告：須逐日查原報；不可僅因作品在1930年代問世，就說1949某戲院正在放映。

- [ ] 制服和徽章：須查具體軍隊、警察機構與月份，不能把後來定型樣式倒套。

- [ ] 照片出處優先保留攝影人、原始日期、收藏機構與館藏號；本篇提供參考連結，不附未獲許可的商業攝影重製圖。

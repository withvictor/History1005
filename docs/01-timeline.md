查核日期：2026-10-03。主體約1860–1949年；1858年只作開港背景。這是小說取材的年代定位工具，不是完整政治通史。

<a id="section-0024"></a>

## 使用方式與界線

- 「史實」是有來源的事件或制度背景；「生活查證提示」是由事件提出的研究問題與創作推論，並非已證實每個人物都會遇到的經驗。

- 同列並置不表示因果或同步轉變。臺灣1895–1945年在日本殖民統治下；1912年中華民國建立、1928年南京國民政府名義統一，都不是臺灣換政權的年份。[[CH05](../sources/10-full-timeline.md#source-ch05)、[HX02](../sources/05-chronology.md#source-hx02)]

- 大陸亦不是單一行政空間：租界、日軍占領區、國民政府控制區、中共根據地，以及東北的不同政權和鐵路權益區，必須按城市、街區與年月判定。

## A 晚清 1860至1911

<a id="section-0029"></a>

### 01 1860年 背景追溯1858年

- 大陸史實：第二次鴉片戰爭後條約體系擴張；英法軍隊進入北京，圓明園遭焚毀。外交使節駐京、口岸及外商活動的制度環境改變。[[CH01](../sources/10-full-timeline.md#source-ch01)]

- 臺灣史實：1858年天津條約把淡水、安平列為通商口岸，後增開雞籠與打狗；開港後海關記錄茶、樟腦、糖與進口洋貨。[[HX03](../sources/05-chronology.md#source-hx03)]

- 生活查證提示：港口工人、茶商、翻譯與內陸農戶的接觸程度不同；先查實際開關日期、港口和貨品，不把條約簽訂等同當地立即全面開放。

<a id="section-0033"></a>

### 02 1874年

- 大陸史實：清廷仍在洋務、自強及海防改革脈絡中；1870年代新式企業、交通與軍事技術成為改革議題。[[HX01](../sources/05-chronology.md#source-hx01)]

- 臺灣史實：日本出兵臺灣南部，發生牡丹社事件；隨軍通譯水野遵留下相關紀錄。[[CH02](../sources/10-full-timeline.md#source-ch02)]

- 生活查證提示：涉及原住民族、船難者、通譯或地方協商，需對讀部落口述與中、日文材料；不要只讓帝國公文決定誰是「合法」居民。

<a id="section-0037"></a>

### 03 1885年下詔建省 1887年行政設置完成

- 大陸史實：清帝國調整臺灣治理，劉銘傳出任首任臺灣巡撫；此為同一帝國內的行政重組。[[CH03](../sources/10-full-timeline.md#source-ch03)]

- 臺灣史實：1885年下詔與1887年建省行政工作完成，是可分辨的兩個階段。[[CH03](../sources/10-full-timeline.md#source-ch03)]

- 生活查證提示：戶籍、衙署、地址和官銜需要查當年用法；不能把後來定型的省制一次性放入1885年所有場景。

<a id="section-0041"></a>

### 04 1891年 1893年

- 大陸史實：仍為晚清時期；本列以臺灣交通變化作比較，不宣稱各地鐵路同步發展。

- 臺灣史實：基隆—臺北鐵路1891年通車，臺北—新竹1893年通車。[[HX04](../sources/05-chronology.md#source-hx04)]

- 生活查證提示：寫1890年代人物不能乘坐尚未全通的西部縱貫線；到站、轉運、票價與候車時間須另查。

<a id="section-0045"></a>

### 05 1895年4月 其後持續軍事衝突

- 大陸史實：甲午戰敗與《馬關條約》加深改革危機；遼東半島另經三國干涉與還付，不能把遼東和臺灣後續命運混為一談。[[HX01](../sources/05-chronology.md#source-hx01)、[CH04](../sources/10-full-timeline.md#source-ch04)]

- 臺灣史實：臺灣、澎湖割讓日本；5月臺灣民主國成立，其後日軍進軍；日本宣布平定後抗日衝突仍持續。[[CH05](../sources/10-full-timeline.md#source-ch05)]

- 生活查證提示：條約、登陸、城市占領、地方官署接管不是同一天。人物的去留與身分變更，要落到所在地和月份。

<a id="section-0049"></a>

### 06 1898年

- 大陸史實：戊戌變法短暫展開後受挫。[[HX01](../sources/05-chronology.md#source-hx01)]

- 臺灣史實：日本殖民政府設臨時臺灣土地調查局，同年開始土地調查。[[CH05](../sources/10-full-timeline.md#source-ch05)]

- 生活查證提示：可查讀書人的升學／任官想像，以及農戶、地主遇到丈量、地權登記的差異；政策目標不等於人人接受。

<a id="section-0053"></a>

### 07 1900至1901年

- 大陸史實：義和團事件及外軍介入後，清廷自1901年起推行更廣泛的新政。[[HX01](../sources/05-chronology.md#source-hx01)]

- 臺灣史實：1901年設總督府專賣局、臨時臺灣舊慣調查會。[[CH05](../sources/10-full-timeline.md#source-ch05)]

- 生活查證提示：北京的戰亂經驗與臺灣制度調查不能共享一套背景；店舖、宗教或家族慣習須區分官署紀錄與居民實踐。

<a id="section-0057"></a>

### 08 1904至1905年

- 大陸史實：日俄戰爭在東北等地展開；1905年《樸茨茅斯條約》後，日本在南滿權益擴大，1906年滿鐵成立、1907年營業。清廷亦於1905年廢除科舉。[[CH04](../sources/10-full-timeline.md#source-ch04)、[HX06](../sources/05-chronology.md#source-hx06)、[HX09](../sources/05-chronology.md#source-hx09)]

- 臺灣史實：已在日本殖民統治下；1905年進行日治首次全島戶口調查。[[CH05](../sources/10-full-timeline.md#source-ch05)、[HX07](../sources/05-chronology.md#source-hx07)]

- 生活查證提示：東北車站周邊與清朝地方官管轄須分辨；長輩科舉資歷、新式學校與臺灣殖民教育也不是同一軌道。人口調查的分類不等於人物自我認同。

<a id="section-0061"></a>

### 09 1908年

- 大陸史實：仍為清末改革時期，非民國。[[HX01](../sources/05-chronology.md#source-hx01)]

- 臺灣史實：西部縱貫鐵路全通。[[HX05](../sources/05-chronology.md#source-hx05)]

- 生活查證提示：通車後可提出跨城旅行場景，但需以同年時刻表、票價和接駁核實，不用今日車程倒算。

<a id="section-0065"></a>

## B 民國初期與日治臺灣 1911至1928

<a id="section-0066"></a>

### 10 1911年10月至1912年2月

- 大陸史實：武昌起義後各省革命展開；1912年中華民國建立，清帝於2月退位。新政府並未立即取得全國有效控制。[[HX09](../sources/05-chronology.md#source-hx09)、[CH04](../sources/10-full-timeline.md#source-ch04)]

- 臺灣史實：日本殖民統治持續。[[CH05](../sources/10-full-timeline.md#source-ch05)]

- 生活查證提示：公文紀年、官署名與民間習慣的更替有時差；臺灣不能僅因換算為民國元年就出現民國地方政府。

<a id="section-0070"></a>

### 11 1913年3月及同年二次革命

- 大陸史實：宋教仁3月20日在上海遇刺；同年爆發反袁的二次革命，後遭鎮壓而失敗。本表不把「袁世凱親自下令行刺」寫成已無疑義的定論。[[CH41](../sources/10-full-timeline.md#source-ch41)、[CH42](../sources/10-full-timeline.md#source-ch42)]

- 臺灣史實：日本殖民統治持續，民國議會危機不構成臺灣政權更替。[[CH05](../sources/10-full-timeline.md#source-ch05)]

- 生活查證提示：上海人物可能接觸不同報紙的案情與指控；必須區分角色聽到的傳聞、政黨說法及敘事者確認的事實。

<a id="section-0074"></a>

### 12 1915年

- 大陸史實：日本向中國提出二十一條要求；12月袁世凱推動中華帝國帝制，宣布1916年為洪憲元年；12月25日雲南反袁護國起義展開。[[HX10](../sources/05-chronology.md#source-hx10)、[CH42](../sources/10-full-timeline.md#source-ch42)、[CH43](../sources/10-full-timeline.md#source-ch43)]

- 臺灣史實：8月發生西來庵／噍吧哖事件。[[CH05](../sources/10-full-timeline.md#source-ch05)、[HX12](../sources/05-chronology.md#source-hx12)]

- 生活查證提示：抵制日貨、查禁、拘捕或宗教組織的具體參與，須查當地記錄；不同地區的反日活動並非同一組織指揮。

<a id="section-0078"></a>

### 13 1916年

- 大陸史實：3月22日袁世凱宣布取消帝制；同年去世，地方軍事勢力競逐加劇。[[CH42](../sources/10-full-timeline.md#source-ch42)、[HX01](../sources/05-chronology.md#source-hx01)]

- 臺灣史實：日治制度延續，不能把北京權力更替當成臺灣官署改組。[[CH05](../sources/10-full-timeline.md#source-ch05)]

- 生活查證提示：洪憲紀年、帝制籌備、取消帝制與袁去世需分開；帝制籌備不能等同所有官民已認同新皇帝。北京、廣州及東北的軍政權威亦不同。

<a id="section-0082"></a>

### 14 1919年5月4日 臺灣同年10月

- 大陸史實：北京學生抗議引出五四運動；事件日期與較長時段的新文化潮流應分開。[[HX13](../sources/05-chronology.md#source-hx13)]

- 臺灣史實：10月田健治郎出任首位文官臺灣總督。[[CH05](../sources/10-full-timeline.md#source-ch05)]

- 生活查證提示：街頭抗議、報刊傳播與學生家庭衝突可作研究方向；文官總督不代表殖民統治或警察權力消失。

<a id="section-0086"></a>

### 15 1920年

- 大陸史實：仍處地方軍政競爭、城市治理各異的民國前期。[[HX01](../sources/05-chronology.md#source-hx01)]

- 臺灣史實：行政區改為五州二廳；1926年再成為五州三廳。[[HX08](../sources/05-chronology.md#source-hx08)]

- 生活查證提示：書信地址、戶籍與公學校隸屬要按改制前後核對；不可用今天的縣市名稱直接替換。

<a id="section-0090"></a>

### 16 1921年2月 10月

- 大陸史實：2月15日廣州市市政廳成立，下設公安、公用、財政、衛生、教育、工務六局；同年中國共產黨成立。[[CH06](../sources/10-full-timeline.md#source-ch06)、[HX01](../sources/05-chronology.md#source-hx01)]

- 臺灣史實：臺灣議會設置請願運動展開；10月17日臺灣文化協會成立。[[CH05](../sources/10-full-timeline.md#source-ch05)、[HX14](../sources/05-chronology.md#source-hx14)]

- 生活查證提示：廣州街市管理和臺灣文化講演是不同形式的公共生活；參與者、場所及語言要另查。

<a id="section-0094"></a>

### 17 1923年4月15日

- 大陸史實：民國前期持續；本列以臺灣新報刊作同步定位。

- 臺灣史實：《臺灣民報》創刊號刊行，原件紀年為大正12年。[[HX11](../sources/05-chronology.md#source-hx11)、[HX16](../sources/05-chronology.md#source-hx16)]

- 生活查證提示：人物是否讀得到某份報紙，需查刊行地、配送、查禁與識字；創刊不等於每個家庭立即有報可讀。

<a id="section-0098"></a>

### 18 1925年5月至1926年10月

- 大陸史實：上海發生五卅事件；1925年6月至1926年10月的省港大罷工，另把廣州、香港工人與跨境商業捲入長期罷工、封鎖。[[HX17](../sources/05-chronology.md#source-hx17)、[CH38](../sources/10-full-timeline.md#source-ch38)]

- 臺灣史實：日本《治安維持法》擴及臺灣等殖民地的法令於5月公布。[[CH05](../sources/10-full-timeline.md#source-ch05)]

- 生活查證提示：工人停工與商店營業、社團集會及思想查禁可連到日常，但不能把上海事件的具體進程複製到臺灣。

<a id="section-0102"></a>

### 19 1926至1927年

- 大陸史實：北伐推進；1927年國共合作破裂與清黨造成重大政治暴力。同年7月7日上海特別市政府成立。[[CH36](../sources/10-full-timeline.md#source-ch36)、[CH07](../sources/10-full-timeline.md#source-ch07)]

- 臺灣史實：1927年臺灣文化協會分裂，7月10日臺灣民眾黨成立。[[HX15](../sources/05-chronology.md#source-hx15)]

- 生活查證提示：人物所屬工會、社團、同學或親友網絡可能面臨新的風險；組織名稱與立場須精確到月份。

<a id="section-0106"></a>

### 20 1928年6月 12月

- 大陸史實：北京6月改稱北平；東北6月張作霖遇炸身亡，12月張學良易幟。南京政權達成名義統一，並非各地已完全整合。[[ML17](../sources/06-mainland-1929-1949.md#source-ml17)、[CH04](../sources/10-full-timeline.md#source-ch04)、[HX01](../sources/05-chronology.md#source-hx01)]

- 臺灣史實：臺北帝國大學成立；殖民政權未變。[[HX18](../sources/05-chronology.md#source-hx18)]

- 生活查證提示：北平／北京、奉天及中央政府稱謂不可穿幫；1928年後仍有軍事與地方權力衝突。

<a id="section-0110"></a>

## C 戰爭擴張與生活管制 1929至1945

<a id="section-0111"></a>

### 21 1929年7至12月

- 大陸史實：中東鐵路爭議升級為中蘇武裝衝突；12月22日伯力議定書安排恢復共同管理及邊境和平。[[CH08](../sources/10-full-timeline.md#source-ch08)]

- 臺灣史實：仍屬日治時期；此事件不是臺灣鐵路政權的變更。[[CH05](../sources/10-full-timeline.md#source-ch05)]

- 生活查證提示：東北跨境旅客、鐵路工人和俄語社群的出行、工作與身分風險，需要按車站與衝突月份查證。

<a id="section-0115"></a>

### 22 1930年 臺灣10月27日

- 大陸史實：中原大戰延續國民黨內部軍事衝突；年末對江西中共根據地的第一次大規模圍剿展開。[[CH09](../sources/10-full-timeline.md#source-ch09)]

- 臺灣史實：10月27日霧社事件發生，日軍、警察及其動員力量鎮壓，倖存者其後遭強制遷移。[[CH10](../sources/10-full-timeline.md#source-ch10)]

- 生活查證提示：不要把「1930年代」寫成普遍和平；山地部落的生活破壞與上海消費文化能同時存在。

<a id="section-0119"></a>

### 23 1931年9月18日

- 大陸史實：關東軍製造南滿鐵路爆炸，隨後發動進攻，九一八事變引向東北占領。[[CH11](../sources/10-full-timeline.md#source-ch11)]

- 臺灣史實：日本殖民統治已持續三十餘年，與新遭軍事占領的東北有不同制度歷程。[[CH05](../sources/10-full-timeline.md#source-ch05)]

- 生活查證提示：東北人物跨過此節點時，查車票、學校、警察、報紙和流通貨幣；不可把「滿洲國」提前寫進9月18日前。

<a id="section-0123"></a>

### 24 1932年1月 3月

- 大陸史實：1月28日上海中日戰事爆發；3月日本扶植的滿洲國成立，溥儀起初任執政，1934年才稱帝。[[CH12](../sources/10-full-timeline.md#source-ch12)、[CH11](../sources/10-full-timeline.md#source-ch11)]

- 臺灣史實：日治制度持續；不能因同受日本帝國影響，就把臺灣寫成滿洲國的一部分。[[CH05](../sources/10-full-timeline.md#source-ch05)]

- 生活查證提示：上海閘北與租界的受戰情況不同；東北官署及年號需分1932、1934兩個節點。

<a id="section-0127"></a>

### 25 1935年4月21日 11月4日

- 大陸史實：11月4日起國民政府實施法幣改革，指定銀行紙幣為法償，限制白銀作貨幣使用。[[CH13](../sources/10-full-timeline.md#source-ch13)]

- 臺灣史實：4月21日新竹—臺中大地震造成重大房屋及公共設施損害。[[CH14](../sources/10-full-timeline.md#source-ch14)]

- 生活查證提示：大陸薪資、存款與價錢要標幣種；臺灣災區可查暫居、重建、學校和交通中斷，不將全島寫成同等受災。

<a id="section-0131"></a>

### 26 1936年12月12日

- 大陸史實：張學良、楊虎城扣留蔣中正，西安事變發生。[[CH15](../sources/10-full-timeline.md#source-ch15)]

- 臺灣史實：日本殖民統治持續；西安事變並未使臺灣政府轉由國民政府接管。[[CH05](../sources/10-full-timeline.md#source-ch05)]

- 生活查證提示：人物得知事件的消息來源與立場，應由當時報刊和私人書信判定；後來的抗戰合作結果不宜讓角色預知。

<a id="section-0135"></a>

### 27 1937年7月7日

- 大陸史實：盧溝橋事變發生，中日戰爭進一步擴大；北平進入日軍占領時期。[[CH16](../sources/10-full-timeline.md#source-ch16)、[ML17](../sources/06-mainland-1929-1949.md#source-ml17)]

- 臺灣史實：1937年起皇民化運動加強，涉及語言、風俗及後續戰時動員。[[CH17](../sources/10-full-timeline.md#source-ch17)]

- 生活查證提示：北京學生的停課、遷學與臺灣學生的日語、儀式要求是不同經驗；不能使用一套「抗戰生活」模板。

<a id="section-0139"></a>

### 28 1937年8月13日至12月13日

- 大陸史實：上海戰事8月13日開始；11月日軍占領上海華界主要地區，租界出現「孤島」格局；12月13日南京陷落，其後日軍進行南京大屠殺。耶魯所藏目擊者文書及影像可查，不以單一精確傷亡數取代事件本身。[[CH16](../sources/10-full-timeline.md#source-ch16)、[ML01](../sources/06-mainland-1929-1949.md#source-ml01)、[CH39](../sources/10-full-timeline.md#source-ch39)]

- 臺灣史實：處在日本戰時動員脈絡中。[[CH17](../sources/10-full-timeline.md#source-ch17)]

- 生活查證提示：上海人物避難能否跨界、住在哪一邊、工廠與親屬在何處，是比「全上海淪陷」更有用的問題；租界亦非絕對安全。

<a id="section-0143"></a>

### 29 1938年5月 10月21日

- 大陸史實：10月21日日軍占領廣州，至1945年才結束該占領時期。[[CH06](../sources/10-full-timeline.md#source-ch06)]

- 臺灣史實：5月《國家總動員法》施行範圍擴及臺灣。[[CH05](../sources/10-full-timeline.md#source-ch05)]

- 生活查證提示：廣州人物的店舖、學校與逃難路線應分占領前後；臺灣人物則需查動員令如何落到工廠、家庭或農村。

<a id="section-0147"></a>

### 30 1940年2月11日 3月30日

- 大陸史實：3月30日汪精衛南京政權就職，受日本軍事支持；不能與重慶的國民政府混稱。[[CH19](../sources/10-full-timeline.md#source-ch19)]

- 臺灣史實：2月11日修正戶口規則，開啟臺灣人改日式姓名的申請途徑。[[CH20](../sources/10-full-timeline.md#source-ch20)]

- 生活查證提示：姓名改變須查家庭是否申請、是否獲許與使用場合；不能讓所有臺灣人在1937年即一律改名。

<a id="section-0151"></a>

### 31 1941年12月8日 東亞當地日期

- 大陸史實：太平洋戰爭爆發，日軍進占上海公共租界；「孤島」格局結束。法租界的情形與公共租界不同，不宜以一句「全部租界同日被占」概括。[[ML01](../sources/06-mainland-1929-1949.md#source-ml01)]

- 臺灣史實：1941年皇民奉公會成立，戰時動員進一步組織化。[[CH17](../sources/10-full-timeline.md#source-ch17)]

- 生活查證提示：外僑身分、商店貨源、審查和交通條件會隨戰局改變；跨太平洋日期常相差一天，須標明所在地。

<a id="section-0155"></a>

### 32 1944至1945年 臺北1945年5月31日

- 大陸史實：戰爭延續，東北工業城市1944年亦遭美軍轟炸。[[CH04](../sources/10-full-timeline.md#source-ch04)]

- 臺灣史實：戰爭末期物資短缺、海運受阻；1945年5月31日臺北遭美軍空襲，總督府建築受損。[[CH21](../sources/10-full-timeline.md#source-ch21)、[CH24](../sources/10-full-timeline.md#source-ch24)]

- 生活查證提示：警報、疏開、防空設施和斷水斷電須按地方查；不用未核實的單一傷亡數字製造戲劇效果。

<a id="section-0159"></a>

### 33 1945年8月8至15日 9月2日及地方接收

- 大陸史實：蘇聯8月8日宣告自9日起對日作戰；日本8月15日宣布投降、9月2日正式簽署降書，地方接收另有日期。[[NT27](../sources/09-northeast-1929-1949.md#source-nt27)] 上海市政府9月12日恢復，廣州9月16日舉行受降儀式。[[CH22](../sources/10-full-timeline.md#source-ch22)、[CH23](../sources/10-full-timeline.md#source-ch23)、[CH07](../sources/10-full-timeline.md#source-ch07)、[CH06](../sources/10-full-timeline.md#source-ch06)]

- 臺灣史實：8月投降消息不是10月臺灣行政接收；兩者應分開。[[CH24](../sources/10-full-timeline.md#source-ch24)]

- 生活查證提示：軍隊停火、消息傳到、機關易手、商店復業可能不同步；人物不能8月15日就拿到所有戰後新證件。

<a id="section-0163"></a>

### 34 1945年10月25日

- 大陸史實：戰後國共談判與接收競爭並存，勝利並未確保長期和平。[[CH36](../sources/10-full-timeline.md#source-ch36)]

- 臺灣史實：臺北公會堂舉行受降儀式，陳儀代表接收；臺灣省行政長官公署及警備總司令部開始正式運作。[[CH24](../sources/10-full-timeline.md#source-ch24)]

- 生活查證提示：本表描述實際治理轉換；受降、行政接收、國籍政策與戰後條約的法律問題不可混為一句話。寫居民經驗時查語言、任用、接收與遣返。

<a id="section-0167"></a>

## D 戰後 內戰與多個1949 1946至1949

<a id="section-0168"></a>

### 35 1946年

- 大陸史實：國共和談未能持久，全面內戰於1946年展開。[[CH36](../sources/10-full-timeline.md#source-ch36)]

- 臺灣史實：5月1日臺灣省參議會開議；5月22日臺灣銀行發行臺幣，後通稱舊臺幣。[[CH34](../sources/10-full-timeline.md#source-ch34)、[CH25](../sources/10-full-timeline.md#source-ch25)]

- 生活查證提示：戰後復員、返鄉、就業與通貨膨脹是可查方向；1946年的臺幣不能直接寫成1949年後的新臺幣。

<a id="section-0172"></a>

### 36 1947年2月27日至3月

- 大陸史實：國共內戰持續。[[CH36](../sources/10-full-timeline.md#source-ch36)]

- 臺灣史實：2月27日查緝私菸衝突，28日抗議及公署衛兵槍擊，事件向各地擴大；3月援軍登臺後進行軍事鎮壓及清鄉。[[CH26](../sources/10-full-timeline.md#source-ch26)]

- 生活查證提示：按城市、日期與族群查死亡、逮捕、避難及失聯，不把二二八簡化為單日街頭衝突，也不預設所有同省籍者的行為一致。

<a id="section-0176"></a>

### 37 1948年8月19日前後

- 大陸史實：中華民國政府推出金圓券改革，要求收兌金銀外幣，並凍結價格工資；外交報告記錄其後貨品退出市場與經濟困境。[[CH27](../sources/10-full-timeline.md#source-ch27)]

- 臺灣史實：仍流通舊臺幣，並受戰後通膨及大陸金融動盪影響。[[CH25](../sources/10-full-timeline.md#source-ch25)、[CH32](../sources/10-full-timeline.md#source-ch32)]

- 生活查證提示：薪水面額、實際可買食物、黑市匯率和存款損失必須分開；法幣、金圓券、舊臺幣不能互稱。

名稱提醒：1948年5月20日，國民政府改制為總統府；「中華民國」是國號，與中央機關的正式名稱層級不同。描述改制後情勢時可用「中華民國政府」，史料原題中的舊稱仍須照錄。（[CH44](../sources/14-taiwan-northeast-primary.md#source-ch44)）

<a id="section-0181"></a>

### 38 1948年9月12日至11月2日

- 大陸史實：遼瀋戰役；11月2日瀋陽被解放軍控制，東北軍事格局改變。[[CH28](../sources/10-full-timeline.md#source-ch28)]

- 臺灣史實：仍在中華民國治理下；本列不是中央政府遷臺的日期。[[CH24](../sources/10-full-timeline.md#source-ch24)、[CH34](../sources/10-full-timeline.md#source-ch34)]

- 生活查證提示：戰役史不能替代圍城平民史；長春、錦州、瀋陽的糧食、出城與接管經驗分別查，不以勝負敘事省略平民代價。

<a id="section-0185"></a>

### 39 1949年1月31日 2月2日

- 大陸史實：北平1月31日轉入中共控制；2月2日軍事代表接管原警察局。軍事交接與具體機關接收有不同日期。[[CH29](../sources/10-full-timeline.md#source-ch29)]

- 臺灣史實：中華民國政權仍治理臺灣，中央機關尚處分批移動過程。[[CH24](../sources/10-full-timeline.md#source-ch24)、[CH34](../sources/10-full-timeline.md#source-ch34)]

- 生活查證提示：角色哪天看見新制服、改稱公安局、使用新印章，要查機關而非只套全市紀念日。

<a id="section-0189"></a>

### 40 1949年4月6日 23至24日

- 大陸史實：南京的中華民國政府官員撤離，共軍進入並接管城市；同時代電報區分23日撤退、告示與24日清晨入城報告。[[CH30](../sources/10-full-timeline.md#source-ch30)]

- 臺灣史實：4月6日發生四六事件，軍警在臺大、師院發動逮捕學生的行動。[[CH37](../sources/10-full-timeline.md#source-ch37)]

- 生活查證提示：寫具體24小時時，應查當地街區與報時；歷史紀念日不一定等於每個居民第一次見到新軍隊的時刻。

<a id="section-0193"></a>

### 41 1949年5月20日 5月27日

- 大陸史實：上海市軍事管制委員會5月27日接管上海市政府。[[CH07](../sources/10-full-timeline.md#source-ch07)]

- 臺灣史實：臺灣省戒嚴令5月19日發布、20日零時生效。[[CH31](../sources/10-full-timeline.md#source-ch31)]

- 生活查證提示：上海接管與臺灣戒嚴為兩條並行線；新聞、集會、出入境及報案程序應分別查當時法令和執行，不把後來所有措施提前。

<a id="section-0197"></a>

### 42 1949年6月15日

- 大陸史實：上海已進入軍事管制委員會接管後的階段。[[CH07](../sources/10-full-timeline.md#source-ch07)]

- 臺灣史實：新臺幣發行，舊臺幣四萬元折新臺幣一元。[[CH25](../sources/10-full-timeline.md#source-ch25)、[CH32](../sources/10-full-timeline.md#source-ch32)]

- 生活查證提示：名目金額按四萬比一換算，不等於購買力增加四萬倍；比較租金、工資和菜價要把通膨與換算分開。

<a id="section-0201"></a>

### 43 1949年10月1日

- 大陸史實：中華人民共和國宣布成立，中央人民政府以北京為首都。[[CH33](../sources/10-full-timeline.md#source-ch33)]

- 臺灣史實：繼續由中華民國治理；10月1日不是臺灣由日本轉由國府接管，也不是中央政府全部遷臺之日。[[CH24](../sources/10-full-timeline.md#source-ch24)、[CH34](../sources/10-full-timeline.md#source-ch34)]

- 生活查證提示：國家宣告成立不代表大陸各城同日易手，更不表示內戰所有戰鬥就此停止。

<a id="section-0205"></a>

### 44 1949年10月14日 25至27日

- 大陸史實：解放軍控制廣州；這比北京的建國典禮晚近兩週。10月25–27日金門古寧頭戰役中，共軍登陸遭國軍擊退，顯示10月1日後戰鬥仍在持續。[[CH06](../sources/10-full-timeline.md#source-ch06)、[CH40](../sources/10-full-timeline.md#source-ch40)]

- 臺灣史實：戒嚴與新臺幣制度已施行數月，中華民國中央機關繼續撤退、移駐。[[CH31](../sources/10-full-timeline.md#source-ch31)、[CH25](../sources/10-full-timeline.md#source-ch25)、[CH34](../sources/10-full-timeline.md#source-ch34)]

- 生活查證提示：同一封由廣州往臺北的信，其發信日、路線與收信時點都會影響稱謂及消息；不能把1949全年壓成一天。

<a id="section-0209"></a>

### 45 1949年12月

- 大陸史實：中華民國政府機關離開成都等地，軍事撤退仍在進行。[[CH34](../sources/10-full-timeline.md#source-ch34)]

- 臺灣史實：12月7日政府遷設臺北的決定是重要節點；中央機關、人員、軍隊與家屬的遷移是分批過程，不是人人同日抵臺。[[CH34](../sources/10-full-timeline.md#source-ch34)]

- 生活查證提示：到臺時間、船機航線、工作安置與家人失聯應逐人查。臺灣戰後社會已從1945年開始變化，不能寫成1949年底才「開始民國」。

<a id="section-0213"></a>

## 1949年的日期速查

北平1月31日、上海5月27日、北京建國宣告10月1日、廣州10月14日，是不同事件。[[CH29](../sources/10-full-timeline.md#source-ch29)、[CH07](../sources/10-full-timeline.md#source-ch07)、[CH33](../sources/10-full-timeline.md#source-ch33)、[CH06](../sources/10-full-timeline.md#source-ch06)] 臺灣則另有5月20日戒嚴、6月15日新臺幣與12月中央政府遷設臺北。[[CH31](../sources/10-full-timeline.md#source-ch31)、[CH25](../sources/10-full-timeline.md#source-ch25)、[CH34](../sources/10-full-timeline.md#source-ch34)] 因此每一個1949年場景至少寫明「月份、所在地、實際管轄、人物所用貨幣和消息來源」。

# 1949年人口分布來源

[回總目錄](../README.md) · [人口專題](../docs/09-population-1949.md) · [總來源索引](README.md)

查核日期：2026年10月5日。以下區分官方原表、後出統計整理、學術研究及報紙轉載。未核讀的原表不因數字精確便視為已核；所有1949年數字須連同當時市界與人口類型使用。

<a id="source-pop49-01"></a>

## POP49-01 國家統計局《中國統計年鑑2011》表3-1

- [人口數及構成，官方原表](https://www.stats.gov.cn/sj/ndsj/2011/html/D0301C.HTM)。已核讀1949年列及表註。
- 定位：1949年末總人口54,167萬、城鎮5,765萬／10.64%、鄉村48,402萬／89.36%。
- 口徑：表註將1981年及以前列為戶籍統計數；總人口含現役軍人，城鄉分類中現役軍人計入城鎮。這是後出年鑑的歷史序列，不是1949年普查。

<a id="source-pop49-02"></a>

## POP49-02 李佳洺等〈胡煥庸線兩側人口的空間分異性及其變化〉

- [《地理學報》2017年72卷1期，148–160頁](https://www.dlyj.ac.cn/article/2017/0375-5444/0375-5444-72-1-148.shtml)。已核讀網頁摘要、前言與研究年代說明。
- 用途：人口東密西疏的研究背景，以及1935年和後來統計不可直接等同的提醒。
- 限制：1935年東南側96%的歷史數字及當時面積口徑，不是1949年的精確測量。文章的實證人口普查年份包括1953、1982、1990、2000、2010，不能拿研究圖表當1949逐縣人口圖。

<a id="source-pop49-03"></a>

## POP49-03 〈新中國70年北京人口發展回顧及思考〉

- [中國人民大學北京社會建設研究院刊載頁](https://www.bjsci.ruc.edu.cn/xsyj/4cca00c06ee34224969e9873b1397725.htm)。已核對搜尋可讀段落；完整網頁未能直接開啟。
- 可用範圍：1949年按當年市界常住人口209.18萬；研究按後來現行市界回推為420.10萬。兩者必須保留疆界差異。
- 待查：原統計表與該研究「現行市界」的完整界定。不能把上述常住口徑與其他來源的戶籍值無註解混合。

<a id="source-pop49-04"></a>

## POP49-04 〈單位的早期生成與再生產：以1946—1956年的哈爾濱市為例〉

- [研究PDF來源](https://shfzyj.ajcass.com/Admin/UploadFile/Issue/202105300001/2022/7/20220712015655WU_FILE_0.pdf)。已讀搜尋索引返回的表2內容；PDF直接存取受限，未目視原表。
- 表2列1949年哈爾濱市區人口785,055人。研究轉引市統計局《哈爾濱市經濟社會統計資料1949—1990》（1993）第44頁，以及市委黨史研究室《城市的接管與社會改造·哈爾濱卷》（1999）第578頁。
- 限制：學術轉引，不是本庫已核原始地方統計；只用於市區量級，不推成全東北人口。

<a id="source-pop49-05"></a>

## POP49-05 《臺灣省戶籍統計要覽》（1959）第57頁

- [國家圖書館典藏原始統計頁](https://twinfo.ncl.edu.tw/tiqry/hypage.cgi?HYPAGE=search%2Fmerge_pdf_sd0999.hpg&a=a&dtd_id=11&jid=00240006&page=57&sysid=T0829482&type=s&vol=48060000)。已目視原掃描，印刷第57頁「3.現住人口籍別」，日期「民國三十八年底」。
- 同一原表：全省7,398,200人，其中外國籍1,269人；臺北市484,312、高雄市247,532、臺南市219,529、基隆市140,141，以上都含外國籍。
- 城市數由男女兩列相加，外國籍同樣由男女兩列相加。全表18個縣、市及陽明山管理局的男女合計可加回全省7,398,200人。
- 原表註：包括原件所稱「山地同胞」，不包括流動人口。保留歷史用語的來源脈絡，不把它當現代分類建議。
- 限制：1949年底及當時行政區，不套用1950年後的分縣或今日縣市合併疆界。原表的籍別分類不能直接換成語言、族群、貧富或移民到達年份。

<a id="source-pop49-06"></a>

## POP49-06 內政部《人口統計年刊110年》表77

- [官方PDF](https://www.ris.gov.tw/documents/data/5/2/Demographic_Fact_Book_110.pdf)，表77，印刷第1044頁／PDF第1051頁。已核對表中歷年人口。
- 1949年臺灣地區7,396,931；1950年7,554,399。表的地域不含金門、連江；1949數不含外國籍。
- 和省原表對照：7,398,200減1,269等於7,396,931。兩個總數必須保留是否含外國籍的差別，不能任擇其一而省略口徑。

<a id="source-pop49-07"></a>

## POP49-07 臺北市志人口歷年數字

- [臺北市政府官方PDF](https://www-ws.gov.taipei/001/Upload/430/relfile/41653/7561488/30a62f4f-0a52-4e3d-bc39-ddcd37f6c359.pdf)，印刷第169頁註16。已核對所引數字。
- 1949年484,312；1950年503,450。用於交叉檢查臺北四十多萬至五十多萬的年份，不能把1950年值提前一年。

<a id="source-pop49-08"></a>

## POP49-08 基隆市政府歷年人口

- [基隆市政府資料頁](https://www.klcg.gov.tw/tw/civil/2231-114882.html)。已核對1949年139,820人。
- 與省原表含外國籍140,141人相比，差321人，與原表外國籍數相同。這是人口納入範圍的交叉核對，不能把兩個數當同口徑。

<a id="source-pop49-09"></a>

## POP49-09 曾獻緯《戰後臺灣糧食體制的形構及其變革（1950–1974年）》

- [國立臺灣圖書館收錄的論文PDF](https://www.ntl.edu.tw/public/ntl/4216/%E6%9B%BE%E7%8D%BB%E7%B7%AF%E5%85%A8%E6%96%87.pdf)。國立臺灣大學歷史學系博士論文，2020年。定位印刷第64頁／PDF第76頁。
- 用途：對1946至1949年人口與糧食需求背景的討論。約740萬戶籍數不包含警察局登記的流動人口及軍人之說，轉引林桶法《1949大撤退》第330頁。
- 限制：這是學術二手解釋。「不含軍人」不冒充省原始人口表直接註明的文字；論文題名主要時段為1950–1974年，其他制度不能不加年代便移到1949年。

<a id="source-pop49-10"></a>

## POP49-10 〈天津與巴黎城市空間形態的比較分析〉

- [上海社會科學院留存的論文PDF](https://g-city.sass.org.cn/_upload/article/files/56/7c/1bfb8a284497b61236a789cbd5d4/de413ea9-52d4-476b-b205-7d721f4ed248.pdf#page=2)，原刊《天津大學學報（社會科學版）》2010年。PDF第2頁已核讀。
- 可用範圍：研究列1949年行政區面積151平方公里、市區人口約179萬。它不是現今天津整個直轄市地域的回推人口。

## POP49-11 重慶1949年人口的後出報導與同時代報紙

- [人民網黨史歷史報導，2017年8月1日](https://dangshi.people.com.cn/n1/2017/0801/c85037-29442685.html)，列1949年11月重慶約110萬人口。
- [《人民日報》1949年12月2日第1版鏡像](https://cn.govopendata.com/renminribao/1949/12/02/1/)，亦記面積300平方公里、人口110萬。
- 限制：報導概數，不能視為精確普查；鏡像不是官方原報典藏。只作1949年城市規模，不套今日直轄市疆界。
